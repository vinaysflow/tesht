# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Pramana Protocol, please
report it responsibly by emailing **vinay@aurviaglobal.com** with the
subject line: `SECURITY: <brief description>`.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Your contact information for follow-up

Please do NOT open public GitHub issues for security vulnerabilities.

## What to Expect

- **Acknowledgment within 48 hours** of receipt.
- **Initial assessment within 7 days**, including a triage decision
  (accepted/declined/needs-more-info).
- **Coordinated disclosure timeline** agreed in writing before any
  public disclosure.
- **Credit** in the resulting security advisory (unless you prefer to
  remain anonymous).

## Out of Scope

The following are NOT considered security vulnerabilities:

- Vulnerabilities in third-party dependencies (report to the dependency
  maintainer)
- Issues requiring physical access to a victim's device
- Social engineering attacks
- Denial of service attacks requiring excessive resources
- Vulnerabilities in deployments by third parties

## Supported Versions

Only the latest minor version of Pramana Protocol receives security
updates. Earlier versions may be patched on a case-by-case basis.
